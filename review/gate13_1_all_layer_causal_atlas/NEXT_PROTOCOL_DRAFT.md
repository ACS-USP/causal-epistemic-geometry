# Next protocol draft — second prospectively useful source task

Status: **DRAFT ONLY — NOT AUTHORIZED FOR EXECUTION**.

Because Gate 13.1 produced strong cross-model replication, the next priority is a second objective task on which a task-appropriate textual CAREFUL policy is prospectively expected to help. The task and evaluator must be qualified before activation outcomes and must not reuse the failed character-count source as if it had replicated.

The future lock should require:

- an exact objective task with deterministic evaluation and non-saturated baseline opportunity;
- a contemporaneous textual CAREFUL source arm that passes a frozen behavioral first-stage gate;
- fixed Qwen L27-D75 and Ministral L27-D25 controllers, with no new layer/dose/controller search;
- separately frozen, architecture-matched random banks for each model;
- independent-primary two-rollout estimands for accuracy, validity/evaluability, G, C, D, rescue, and damage;
- a fresh development sample and item-cluster inference;
- explicit cross-task and cross-model interpretation boundaries;
- Q2, Q3, reserved CRUXEval IDs, and confirmatory holdout remaining closed.

Candidate instruments may be reviewed prospectively, but no model output may be used to choose among them. A new principal authorization, premortem, and protocol lock are required before any inference.
