# Narrow interpretation of API source qualification

`API_CONTRACT_EXACTNESS` was strongly representation-readable at both inspected
source locations, but it did not satisfy the frozen minimum behavioral/textual
excess-separation requirement relative to within-source stochastic variation.

This supports only the narrow observation:

\[
\boxed{\text{representational separability}\not\Rightarrow
\text{qualifying functional source separability}.}
\]

It does **not** show that API exactness is unrepresented, behaviorally
irrelevant, impossible under another construction, or evidence against
geometry.

The implementation confirms the reported resolution. Across 24 held-out items,
cross-polarity disagreement averages 96 binary comparisons (four per item),
while within-polarity disagreement averages 48 comparisons (two per item).
Both can be expressed on denominator 96. The observed excess was:

\[
0.375-0.354166\ldots=\frac{36}{96}-\frac{34}{96}
=\frac{2}{96}=0.020833\ldots
\]

The frozen `>=0.03` gate therefore required at least `3/96 = 0.03125` at this
granularity. This methodological note does not change the historical threshold
or result.
