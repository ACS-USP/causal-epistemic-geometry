# Research portfolio strategy

The causal-geometry program (B′) is high risk and high upside. It uniquely needs
open weights, internal hooks, careful stochastic estimands, expensive
instrument qualification, and evidence that geometry adds predictive value
beyond random directions and repeated sampling.

A separate program provisionally called **Recycled Evidence** has a different
risk profile: lower compute, exact Bayesian or probabilistic oracles, provenance
DAGs, paired counterfactual evaluation, and direct relevance to retrieval and
evidence reuse. It should remain a separate repository and scientific question.
This repository must not import, modify, or couple its history to that project.

The correct portfolio decision is not to force B′ to succeed because it has
sunk engineering cost. Run one final structured sprint with explicit gates:

1. finish offline statistical and repository repairs;
2. test full non-thinking generation cheaply;
3. reproduce a published positive control;
4. run a small substrate race;
5. run one micro-Q1 only after qualification.

Advance B′ only with a qualified instrument, validated intervention machinery,
and an identifiable effect. Otherwise pause it while a lower-risk program
produces independent scientific value. Pausing is not abandonment and does not
convert instrument failures into a negative theory result.
