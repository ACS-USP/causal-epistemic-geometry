# Scientific constitution

This document defines the claim hierarchy and non-negotiable evidence boundaries
for Causal Geometry of Epistemic Complementarity. It is normative. Individual
protocols may narrow these rules but may not silently weaken them.

## Program questions

The long-term question is:

> Can internal representation and intervention geometry predict and causally
> control which blind spots competence-preserving model variants exhibit?

The evidence ladder separates three questions:

1. **Q1 — causal error-profile control.** Can one controlled activation
   intervention change where a frozen model fails beyond ordinary stochastic
   resampling without merely making it worse?
2. **Q2 — geometry predicts error geometry.** Across pre-specified
   interventions, does an intervention-space metric predict a held-out
   error-profile metric?
3. **Q3 — collective utility.** Can a realizable selection or aggregation
   mechanism exploit the measured complementarity?

Q1 is not established by Q2-like activation structure. Q2 is not established
by a single successful steering direction. An oracle pair is not Q3.

## Four claims that must remain separate

- **Behavioral difference:** outputs differ.
- **Semantic error difference:** exact task outcomes differ.
- **Useful complementarity:** errors move beyond resampling while competence is
  preserved.
- **Implementable collective gain:** an outcome-independent mechanism realizes
  utility without oracle access.

Each implication requires its own evidence. Response diversity alone is not an
epistemic result. Low error correlation obtained by destroying treatment
accuracy is not useful complementarity.

## Minimal Q1 estimand discipline

For item `t`, condition `j`, and independently sampled rollout `r`, let

```text
e_tjr ~ Bernoulli(p_tj)
```

where `e=1` is a genuine semantic error under an exact or audited objective
evaluator. Operational failures—invalid format, unfinished thinking, runtime
error—remain separate diagnostics. They may count against raw system utility,
but they cannot be used to manufacture a semantic-error regime.

Q1 must report competence and complementarity together. The primary operational
seed regime uses independent seed banks. Matched common-random-number coupling
is a secondary causal diagnostic whose answer may depend on that coupling.

## Instrument qualification before intervention

An instrument must produce:

- objective, low-ambiguity outcomes;
- high valid completion;
- substantial genuine correct and genuine wrong mass;
- enough independent items for paired inference;
- no dependence on arbitrary answer slots or outcome-dependent parsing;
- a cost and security profile compatible with replication.

Baseline-only instrument selection may choose a prospective difficulty regime.
It must never select individual items, prompts, token budgets, layers, vectors,
or alphas according to steering outcomes.

## Development regimes

`EXPLORATION` is a cheap 5–20 item screen. Failure is a useful gate. Minimal
artifacts and explicit cost bounds are sufficient; confirmatory ceremony is
not.

`DEVELOPMENT_LOCK` begins only after a genuine signal. It freezes code, schemas,
model policy, parser, seed regimes, estimands, controls, cost, and validators
before larger evaluation.

`CONFIRMATORY` requires sealed hypotheses and estimands, a source commit, an
untouched holdout, exclusion rules, and no outcome-dependent adaptation.

## Geometry discipline

Flat cosine and normalized Euclidean distance are the Q2 baseline. More complex
metrics must earn their place against that baseline:

1. flat vector geometry;
2. held-out, regularized activation-covariance or whitened geometry;
3. behavioral pullback/pushforward or pre-specified finite-difference geometry.

Pairwise matrix associations use label permutations (QAP/Mantel-style), not
independent-pair p-values. Manifold or Riemannian language is forbidden until a
simpler metric fails for an identified reason and sufficient data support the
extra degrees of freedom.

## Positive and negative controls

Before interpreting a null original-Q1 pilot, the stack must reproduce a
published, technically adjacent activation intervention in a separately frozen
positive-control protocol. Alpha-zero identity, norm-matched random directions,
independent baseline resampling, and intervention manipulation checks remain
mandatory negative or calibration controls.

A failed positive control blocks interpretation of an original-Q1 null as
evidence against the scientific hypothesis.

## Engine and provenance equivalence

An optimized engine may replace a reference engine only after exact token or
exact discrete-outcome equivalence at the level required by the protocol. A new
canonical engine may instead be frozen prospectively before outcome collection,
but it must be used symmetrically across all conditions, preserve per-row RNG
semantics, and remain unchanged within the experiment.

Every scientific row must resolve to model/revision, prompt hash, item, seed,
condition, intervention, parser/evaluator, engine, source commit, and artifact
manifest.

## Stop rules

Stop rather than rescue an instrument when difficulty comes mainly from
truncation, parser fragility, arbitrary answer surfaces, evaluator ambiguity,
unsafe execution, or near-floor/ceiling semantic performance. Do not expand a
weak instrument because engineering effort has already been spent.

The final structured sprint is prospectively bounded to offline repairs, a
full-generation non-thinking smoke, a published positive control, a small
model-policy-instrument substrate race, and one micro-Q1. Continue toward Q2
only if the sprint yields both a qualified instrument and a validated positive
control, and the micro-Q1 identifies an intervention effect beyond resampling.

Otherwise pause this program pending materially better model access,
instrumentation, or external evidence. That is portfolio management, not a
negative scientific claim.
