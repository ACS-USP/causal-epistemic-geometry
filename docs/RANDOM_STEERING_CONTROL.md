# Random steering controls

Q1 development must not rely on a single hand-selected direction. The package
therefore provides deterministic random unit vectors, orthogonal random
directions, and norm matching without running a null campaign by default.

The control question is simple: if random directions create the same apparent
error complementarity as a semantic or contrast direction, the semantic or
geometric interpretation is weakened. Matching norms helps distinguish direction
effects from a trivial intervention-magnitude effect.

These helpers are controls, not evidence and not a vector-selection procedure.
Use a pre-specified small control set only after the principal researcher
reviews the development protocol.
