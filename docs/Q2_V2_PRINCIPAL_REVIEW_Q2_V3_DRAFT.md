# Q2 V2 principal review and Q2 V3 draft

The frozen Q2 V2 classification remains
`Q2_V2_NO_FAMILY_HELDOUT_GEOMETRY_SIGNAL`. A local-only principal-researcher
review exactly reproduced all primary metrics and then performed explicitly
post-hoc diagnostics on the immutable artifacts.

The main new finding is that M2's finite-secant association is broad across
families but largely tracks intervention strength. A four-feature dose and
delta-norm nuisance model reached held-out rho 0.443 and RMSE ratio 0.929.
Adding M2 reduced held-out RMSE by only about 0.55%; residual rho was 0.054 and
the exploratory family-block QAP p-value was 0.374. This weakens a specifically
relational-geometry interpretation without changing the historical composite
null or erasing M2's advantage over M0/M1.
